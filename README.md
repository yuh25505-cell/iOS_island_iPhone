# 岛屿机 iOS 版

> 版本 v0.1　包名 `com.island.phone`　从安卓版 `island-iphone` 搬来，改成苹果原生 App。

岛屿机是一台装在 iPhone 里的“小手机”：外观和手感完全照苹果手机做（液态玻璃），里面的每个 App 都围绕一件事服务——**让 AI 角色（char）像真人一样生活，而不是围着你（user）转**。

- 纯原生 iOS App（Swift + SwiftUI），不是网页套壳。
- 只自己安装使用，不上架。
- 用 GitHub Actions 的苹果电脑机器打包。

---

## 一、核心玩法：活人感

- char 有自己的**日程**：上课、上班、吃饭、睡觉、出门，忙的时候回消息会慢，睡着了不回。
- char 有自己的**朋友和家人**（NPC），会聊天、发朋友圈、在论坛发帖。
- char 会**一年年成长**：学生到工作，工作到升职（屿年）。
- 回复风格有专门的“去 AI 味”规则：说人话、会分段发、不总结、不说教、不总附和。
- 记忆分开：每个 char 的记忆、相册、日程互不串。

---

## 二、整体界面

1. **开场动画**：液态玻璃雨滴落在屏幕中间，晕开，浮现“请让这座孤岛 / 因你们而拥有属于它的故事”。
2. **登录 / 注册**：登录后永不掉线。
3. **主屏幕**：图标可拖动、可进文件夹、可放组件、可翻页，和真 iPhone 一样。
4. **各个 App**：点开后有苹果式的打开和关闭动画，支持左滑 / 右滑返回上一步。
5. 全局支持**日间 / 夜间 / 跟随系统**，也可以固定日间或夜间。

## 五、记忆怎么记

- **读多少聊天记录**：你自己定（上下文深度）。
- **传统总结记忆**：聊到你设定的条数后，自动总结成短记忆。
- **向量记忆**：把内容变成“意思”存起来，需要时按相关度翻出来（重点功能）。
- 两种可以单独用，也可以一起用。

## 六、App 之间怎么互通

互通都是**双向**的：A 影响 B，B 也影响 A。

| 互通的两边 | 怎么通 |
|---|---|
| 聊天 ⇄ 日历 | char 的日程决定忙闲、睡醒；聊天里约好的事自动进日历；日历到点 char 会主动找你 |
| 聊天 ⇄ 时钟 | 你说“明早 7 点叫我”自动定闹钟；闹钟响后 char 会发消息 |
| 聊天 ⇄ 倒数日 | 聊天里提到的纪念日自动记下；到日子 char 主动祝福 |
| 聊天 ⇄ 相册 | char 能截聊天、拍照存相册；相册的图能发回聊天 |
| 聊天 ⇄ 天气 | char 所在地天气影响话题（下雨会提醒带伞）；聊到哪个城市可更新地点 |
| 聊天 ⇄ 备忘录 | char 的碎碎念来自聊天；你允许的备忘录内容 char 能看到 |
| 聊天 ⇄ 电话 | 聊天里能拨号；通话内容总结进记忆 |
| 聊天 ⇄ 相遇 | 线下剧情计入记忆，聊天自然衔接“刚见完面” |
| 聊天 ⇄ 美团 | char 给你点外卖，你给 char 点；日历里的饭点会触发 |
| 聊天 ⇄ 论坛 | char 发的帖子聊天里会提；你能把帖子分享给 char |
| 聊天 ⇄ 音乐 | 一起听歌；分享歌曲；char 的听歌喜好会被记住 |
| 屿年 ⇄ 全部 | 年龄、身份一变，日历（上学→上班）、聊天口吻、论坛身份、世界书一起变 |
| 关联账号 ⇄ 聊天/朋友圈/论坛/备忘录 | 关联后互相能看到对方的这些内容 |
| 论坛 ⇄ 文学城 | 帖子可以催生同人文；文章可以被拿到论坛讨论 |
| 栖迟 ⇄ 记忆 | 梦可参考记忆；做完后可选择是否写回记忆 |
| 情侣空间 ⇄ 倒数日/天气/时钟/音乐/相册/备忘录 | 见下面“情侣空间玩法” |
| 外观 ⇄ 全部 | 图标、壁纸、字体全局生效 |
| 预设、世界书 ⇄ 所有会调用 AI 的 App | 统一从这里取提示词和设定 |
| 番外笺 | 不互通（按你的要求） |

## 七、情侣空间玩法（构思，待你定）

**你已有的：**便利贴碎碎念；每天互发“我爱你”，满一年有大奖励；中断后要完成“重燃火花”才能接着算。

**我建议加的（按陪伴感和常用程度排）：**

1. **每日一问**：每天一个小问题，你和 char 各自回答，两边都答完才同时揭晓。
2. **晚安仪式**：每晚互道晚安，连续天数涨“小岛”，岛上会长树、房子、灯塔。
3. **共同小岛**：双方的连续天数、纪念日让一座小岛慢慢长大，看着就有成就感。
4. **交换日记**：一人一天写一段，轮流写，翻页像本子。
5. **时间胶囊**：写一封信，选个未来日子才能打开（连倒数日）。
6. **愿望清单**：一起列想做的事，完成了打勾，可以接相遇做成线下剧情。
7. **异地模式**：并排显示两边天气和时间，睡前提醒对方（连天气、时钟）。
8. **一起听歌**：同步播放，歌单共享（连音乐）。
9. **心情同步**：每天点一个心情，对方看得到，对方也会回应。
10. **重燃火花任务**：断了后随机抽任务（写长信、给对方点外卖、一起通话），完成才能续上。

## 八、技术选择（简单说）

- 界面：全部苹果原生组件（SwiftUI），长聊天滑动不卡。
- 数据：存在手机本地的系统数据库里（SwiftData），每个账号独立。
- 联网：苹果自带网络库，自己解析 AI 的流式输出，更稳。
- 后台：用系统后台任务和通知，AI 回复时切后台也能收到。
- 登录后端：Cloudflare 免费额度（后端沿用，不用重做）。
- 液态玻璃：直接调用苹果官方的玻璃接口（`glassEffect`），不再自己画；系统版本低的手机自动换成普通磨砂。
